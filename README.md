## 🚀 Sobre el Proyecto

Este repositorio contiene el código fuente de mi **Portafolio Profesional**, diseñado para mostrar mi experiencia, habilidades técnicas y proyectos desarrollados.

El sitio está construido con **Astro**, priorizando:

* **Máximo rendimiento** (puntuación 100/100 en Lighthouse) ⚡
* **Accesibilidad real** ♿
* **Diseño moderno y responsivo** 🎨
* **Mínimo JavaScript enviado al cliente** gracias a la arquitectura de islas 🏝️

---

## ✨ Características Principales

* ⚡ **Rendimiento Extremo:** Astro entrega HTML estático y optimizado.
* 🎨 **Diseño Moderno:** TailwindCSS para una UI limpia, sólida y coherente.
* 🌙 **Dark / Light Mode:** Automático según el sistema o selección del usuario.
* 📱 **Responsividad Total:** Desde móviles hasta pantallas 4K.
* 🧩 **Interactividad Inteligente:** Islas con React solo donde es necesario.
* 🔍 **SEO de Primer Nivel:** Sitemap, OpenGraph, meta dinámicas.
* 📦 **Código Modular:** Componentes reutilizables en .astro y .tsx.

## 💻 Instalación y Ejecución

### **1️⃣ Clonar repositorio**

```bash
git clone https://github.com/jscamposx/portafolio.git
cd portafolio
```

### **2️⃣ Instalar dependencias**

```bash
npm install
```

### **3️⃣ Iniciar servidor de desarrollo**

```bash
npm run dev
```

📍 Servirá el proyecto en: **[http://localhost:4321](http://localhost:4321)**

### **4️⃣ Compilar para producción**

```bash
npm run build
```
